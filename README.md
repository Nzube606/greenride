# GreenRide

A full-stack web application designed to simplify campus transportation by connecting passengers with available drivers through a centralized platform.

> **Note:** This project is currently under active development as my final-year project. Features, architecture, and documentation will continue to evolve as development progresses.

## Features

- User registration and authentication
- Separate interfaces for passengers, drivers, and administrators
- Ride request and management system
- Real-time communication using Socket.IO
- RESTful backend API
- MongoDB database integration

## Tech Stack

**Frontend**

- HTML
- CSS
- JavaScript

**Backend**

- Node.js
- Express.js
- MongoDB
- Mongoose
- Socket.IO
- JSON Web Tokens (JWT)
